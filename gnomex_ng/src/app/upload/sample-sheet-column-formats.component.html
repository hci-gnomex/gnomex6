File Types

Tab delimited text (.txt)   One row per sample, columns separated by tabs.

Excel workbook (.xlsx, .xls)
  - Only the first visible sheet is read. Put the samples on the first sheet.
  - Each cell is imported as the text shown in Excel (formulas are calculated,
    numbers keep their displayed format).
  - Cells showing an error (#N/A, #REF!, ...) are imported as blank.
  - Merged cells: only the top-left cell has a value.
  - Checkbox columns need Y or N; TRUE / FALSE are not accepted.
  - Password protected workbooks and binary (.xlsb) workbooks cannot be read.
